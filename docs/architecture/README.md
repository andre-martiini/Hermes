# Hermes Architecture

Este diretório concentra os artefatos canônicos de arquitetura do Hermes.

## Ordem de leitura

1. `01-vision-and-boundaries.md`
2. `02-operating-model.md`
3. `03-governance-and-tooling.md`
4. `04-roadmap.md`

## Objetivo

Estabelecer uma base estável para evoluir o Hermes de um sistema operacional de tarefas com recursos de IA para uma plataforma de orquestração de agentes, memória estruturada e execução controlada.

## Regras

- Estes documentos descrevem a arquitetura-alvo e as decisões-base.
- Implementações futuras devem referenciar estes contratos antes de introduzir novos fluxos, agentes ou integrações.
- Em caso de conflito entre comportamento atual do código e estes documentos, o conflito deve ser explicitado e resolvido com decisão de arquitetura, não com expansão implícita do código.
