# Arquitetura

Diferente das categorias [Operações](/docs/okf/operacoes/index.md), [Integrações](/docs/okf/integracoes/index.md) e [Guias](/docs/okf/guias/index.md) — que são runbooks pontuais —, os documentos abaixo são **referência estrutural viva**: descrevem como o sistema é organizado hoje e precisam ser atualizados sempre que essa estrutura mudar. Ver [como manter este bundle atualizado](/docs/okf/manutencao.md) antes de editar qualquer um deles.

- [Schema do Firestore](/docs/okf/arquitetura/schema-firestore.md) — coleções, campos, quem escreve e relações.
- [Mapa de Cloud Functions](/docs/okf/arquitetura/cloud-functions.md) — funções exportadas, triggers e o que fazem.
- [Convenções de frontend](/docs/okf/arquitetura/convencoes-frontend.md) — stack, estrutura de pastas, padrões de componentes e estilo.
